### Welcome to our GitHub Repository

Fast, self-hosted URL shortener for WordPress. Branded short links on your own domain with privacy-friendly click tracking, QR codes and password-protected links. No third-party service, no monthly fee.

More information can be found at [handyplugins.co](https://handyplugins.co/).

## Installation ##

Install Clicklet URL Shortener from **Plugins → Add New** in your WordPress admin, or download it from [WordPress.org](https://wordpress.org/plugins/clicklet-url-shortener/). Short links are managed under **Short Links**.

Coming from URL Shortify or Pretty Links? Use **Short Links → Import / Export** to migrate your links, click history and groups in one click.
